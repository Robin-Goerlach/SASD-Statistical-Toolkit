# Shared statistical specifications

These contracts are language-neutral and use English as their canonical text.
German explanations appear in [the planning documentation](../docs/de/README.md).
They govern C++ and C# behavior without prescribing identical APIs.

- [CONVENTIONS.md](CONVENTIONS.md): draft statistical/result conventions.
- [DESCRIPTIVE-STATISTICS.md](DESCRIPTIVE-STATISTICS.md): first pilot contract.
- [procedures.json](procedures.json): authoritative procedure IDs and per-language status.
- [PROCEDURE-TEMPLATE.md](PROCEDURE-TEMPLATE.md): contract authoring template.

All current contracts are drafts. Maintainer approval and independent numerical
review are required before implementation. Catalog entries are not specifications.
Future procedure documents must declare their contract version and overrides of
shared defaults. Breaking statistical behavior requires a new contract version.

Gemeinsame fachliche Verträge und Referenzfälle gelten für beide Sprachen.
Die Dokumente sind Entwürfe, keine Implementierungsfreigaben. API-, Build- und
Handbuchdokumentation bleiben im jeweiligen Sprachbereich.
