# Gliederung des C#/.NET-Handbuchs

[English](../en/README.md) · [Gemeinsame Spezifikationen](../../../../spec/README.md)

Status: geplant. Hier gibt es noch keine C#-Statistik-API.

| Kapitel | Inhalt bei Implementierung |
| --- | --- |
| Installation | SDK/Laufzeit/Plattformen, NuGet/Projektabhängigkeit und Math-Fixierung |
| Erste Analyse | Echtes ausführbares Kennzahlenbeispiel mit Interpretation |
| Datenverträge | Arrays/Spans/Matrizen, Eigentum und Fehlwerte |
| Ergebnisse und Fehler | Typisierte Ergebnisse, fehlende Schätzwerte, Exception-/Statuszuordnung |
| Verfahren | Definitionen, Annahmen, Optionen und C#-Beispiele je validiertem Verfahren |
| Numerische Diagnostik | Präzision, Rang/Kondition, Fehler und Konvergenz |
| Integration | Pakete, Adapter und Anwendungs-/Ablaufgrenzen |
| Validierung | Gemeinsame Fälle, unabhängige Referenzen, unterstützte Konfiguration |

Öffentliche APIs erhalten /// XML-Dokumentation zu Domänen und numerischen
Entscheidungen. Die erste Implementierung ersetzt diese Gliederung durch echte
Kapitellinks und geprüfte Restore-/Build-/Test-/Ausführungsbefehle. API-Namen sind offen.
