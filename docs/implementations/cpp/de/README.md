# Gliederung des C++-Handbuchs

[English](../en/README.md) · [Gemeinsame Spezifikationen](../../../../spec/README.md)

| Kapitel | Inhalt bei Implementierung |
| --- | --- |
| Installation | Compiler/Plattformen, CMake/Paketabhängigkeit und Math-Fixierung |
| Erste Analyse | Echtes baubares Kennzahlenbeispiel mit Interpretation |
| Datenverträge | Ranges/Spans/Matrizen, Eigentum, Lebensdauer und Fehlwerte |
| Ergebnisse und Fehler | Optionale Werte, Status-/Fehlerzuordnung und Exceptions |
| Verfahren | Definitionen, Annahmen, Optionen und C++-Beispiele je validiertem Verfahren |
| Numerische Diagnostik | Präzision, Rang/Kondition, Fehler und Konvergenz |
| Integration | Linken, ABI, Adapter und Anwendungs-/Ablaufgrenzen |
| Validierung | Gemeinsame Fälle, unabhängige Referenzen, unterstützte Konfiguration |

Öffentliche Header erhalten Doxygen-Kommentare zu Domänen und numerischen
Entscheidungen. Die erste Implementierung ersetzt diese Gliederung durch echte
Kapitellinks und geprüfte Build-/Ausführungsbefehle. API-Namen sind noch offen.
