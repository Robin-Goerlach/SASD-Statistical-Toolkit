[Shared specifications](../../spec/README.md) contain the canonical mathematical
contracts. [Conformance](../../conformance/README.md) contains reference inputs
and expected results. [Implementation documentation](../implementations/README.md)
and handbooks belong to separate C++ and C# trees.

Normative order: an explicitly approved procedure contract governs its procedure;
shared conventions govern unspecified statistical choices; requirements govern
product behavior; architecture governs placement. Contradictions must be resolved
before implementation, not silently interpreted. Roadmap items and feature
catalog entries are plans, not acceptance evidence. Current contracts are drafts.
